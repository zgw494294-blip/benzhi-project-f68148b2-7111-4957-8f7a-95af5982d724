# 木年轮定年证据发布台

本项目面向历史木构研究团队，把木芯样本建档、Draft 元数据校订、不可变年轮序列修订、确定性交叉定年、争议处置、结构化独立复核、证据冻结、结论凭据发布与验证收束为一条可追溯流程。

服务由 Go 标准库实现，不依赖 Node 或外部数据库。浏览器工作台和同源 JSON API 由同一个 Go 进程提供；数据保存在本地 JSON Lines 事件日志与原子投影快照中。每次写入均检查 `expectedVersion`，并用 `idempotencyKey` 复用首次命令结果。

## 构建

```text
go build ./...
```

## 运行

```text
go run ./cmd/server -addr=127.0.0.1:19081
```

启动后访问 `http://127.0.0.1:19081/`。默认监听地址是 `127.0.0.1:19081`，默认数据目录是 `./data`，可通过 `-data` 指定其他目录。

也可以只设置端口号：

```text
PORT=19123 go run ./cmd/server
```

此时服务绑定 `127.0.0.1:19123`。为避免意外暴露证据数据，服务拒绝非回环监听地址。

## 测试与自检

运行全部测试：

```text
go test ./...
```

运行有界端到端自检：

```text
go run ./cmd/server -selfcheck -addr=127.0.0.1:19081
```

自检使用临时数据目录，在真实回环 HTTP 监听上依次完成建档、序列预检与提交、交叉定年、必要的争议处置、结构化独立复核、冻结就绪预览与摘要确认、发布和完整载荷验证，成功后自行关闭并退出。

## 业务规则

- 档案按 `Draft`、`SeriesSubmitted`、`Analyzed` 或 `NeedsCorrection`、`UnderReview`、`Approved`、`Frozen`、`Published` 受控推进。
- 仅无序列的 `Draft` 档案允许校订元数据；疑似重复采样必须先查看候选并填写继续保存理由。
- 序列提交前服务端逐轮预检文本，并把档案版本、父修订和规范化内容绑定到确认摘要；输入变化会使确认失效。
- 序列修订不可原位覆盖，修订摘要、父修订编号、提交者和提交时间均被保留。
- 交叉定年运行历史可按同一档案只读对比，展示候选名次、得分与质量提示集合的稳定差异。
- 替代序列会立即触发重新分析，旧分析及旧复核决定不能推进新版本。
- 同一当前运行的提示可原子批量解释；任一项过期或无效时整批不写入。
- 未解决的阻断争议不能进入复核；最近序列提交者不能担任独立复核员。复核必须逐项完成固定清单，退回整改需引用退回后的有效业务事件。
- 冻结前返回六个规范证据分区及确认摘要；冻结命令必须携带仍与当前投影一致的摘要，冻结后禁止业务内容变更。
- 公开校验区支持最多 50 个编号或完整 JSON 载荷的混合批次，逐项验证且不修改档案。
- 档案队列支持阶段、遗址、构件、更新时间和阻断项组合筛选，并返回同一快照上的积压统计与稳定游标分页。
